
# Ghazaleh Razi — Portfolio

Personal portfolio of **Ghazaleh Razi**, a Frontend Engineer specializing in Angular and TypeScript, with a focus on enterprise web applications, maintainable architecture, and intuitive user interfaces.

🌐 **Live Website:** [ghazaleh-razi.com](https://ghazaleh-razi.com/)

## Tech Stack

- **Framework:** Next.js 16, React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** GitHub Pages, GitHub Actions

## Features

- Modern, responsive design
- Light, dark, and system themes
- Accessible navigation and interactions
- Professional experience and contact sections
- Dedicated Angular development services page
- SEO metadata, structured data, and sitemap
- Static site generation

## Getting Started

**Requirements:** Node.js 24+ and npm.

Clone the repository:

```bash
git clone https://github.com/ghazaleh-razi/ghazaleh-razi-portfolio.git
cd ghazaleh-razi-portfolio
```

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality Checks

```bash
npm run lint
npm run typecheck
npm run build
node scripts/verify-static-seo.mjs
```

## Deployment

The website uses Next.js static export and GitHub Pages.

- Production builds generate the `out/` directory.
- GitHub Actions handles validation and deployment.
- Merging or pushing to `main` triggers the deployment workflow.

For more details, see the [Deployment Guide](docs/deployment.md).
